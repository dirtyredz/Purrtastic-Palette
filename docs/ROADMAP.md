# ROADMAP — Purrtastic Palette

The mod is **shipped** (v1.1.0 on Nexus, [mod 142](https://www.nexusmods.com/moonlightpeaks/mods/142)).
No committed feature roadmap beyond maintenance; this file records the shape of what's done and what
*could* come next. Prioritised work lives in [BACKLOG.md](BACKLOG.md).

## Done
- **Phase 1 — config recolour.** All six colours + Fur Intensity, live-apply, Mod-Nook-rendered.
- **Phase 2 — wardrobe tab.** Cat Form tab, live preview, swatch/slider/RGB-picker UI, decorated
  headers, revert-on-cancel, ownership gate, custom tab icon.
- **1.0.0 → 1.1.0** release: renamed from `CatColorProbe`, dev tools stripped, packaged, published.

## Possible next (not committed)
- Keyboard / gamepad navigation between swatches (currently 🧊 shelved — see FEATURES).
- Structural tidy-up of the three large files once a change can be verified in-game (see BACKLOG P1).
- Sibling *Palette* mods (Fangtastic = bat, Fintastic = mermaid) reuse this methodology in their own
  standalone repos — no shared code by design (see [DECISIONS.md](DECISIONS.md) ADR-009).
